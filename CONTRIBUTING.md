# Contributing to MoneyPrinterTurboFast

Thanks for considering a contribution to **MoneyPrinterTurboFast**! 

MoneyPrinterTurboFast is an open-source, local-first AI automation studio designed to turn long-form videos into high-retention vertical Shorts, Reels, and TikToks. The project is modular, easy to run, and requires zero paid SaaS subscriptions.

---

## 🧭 Ways to Help

- 🐛 **Report Bugs** via [GitHub Issues](https://github.com/jastfan/MoneyPrinterTurboFast/issues) — please include your OS (Windows/Linux/macOS), Python version, terminal error traceback, and the video URL or action tested.
- 💡 **Suggest Features** — open an issue with the `enhancement` label detailing what content creators need.
- 🔧 **Pick Up a Good First Issue** — check out issues tagged with [`good first issue`](https://github.com/jastfan/MoneyPrinterTurboFast/labels/good%20first%20issue).
- 🌍 **Test Multi-Platform Sources & Publishing** — test feeds from YouTube, TikTok, Instagram, and Facebook and report back edge cases.
- 🪄 **Improve AI Models & Captions** — optimize face-tracking precision, word-by-word caption styles, or prompt engineering for viral hook scoring.
- 📝 **Documentation & Visuals** — add screenshots, demo GIFs, installation guides, or translation support.
